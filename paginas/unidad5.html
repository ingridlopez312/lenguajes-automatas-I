Unidad 5: Análisis Sintáctico

En esta unidad se estudia la fase del compilador encargada de verificar la estructura gramatical del código fuente. Se abordan gramáticas, árboles de derivación, formas normales de Chomsky, conjuntos FIRST y FOLLOW, diagramas de sintaxis y matrices predictivas.

Objetivo de la unidad

Comprender cómo el análisis sintáctico permite comprobar si una secuencia de tokens cumple con las reglas gramaticales de un lenguaje de programación, utilizando gramáticas formales, árboles de derivación y tablas predictivas.

5.1 ¿Qué es el análisis sintáctico?

El análisis sintáctico es una fase del compilador que recibe como entrada la secuencia de tokens generada por el analizador léxico. Su función principal es verificar que dichos tokens estén organizados de acuerdo con las reglas gramaticales del lenguaje.

Mientras el análisis léxico se enfoca en reconocer palabras, símbolos y números, el análisis sintáctico revisa la estructura completa de las instrucciones. Por ejemplo, puede detectar si falta un punto y coma, un paréntesis o si una expresión está mal formada.

Dato importante:

El análisis sintáctico no revisa todavía el significado profundo de una instrucción; solo verifica que su estructura sea correcta según la gramática.

5.2 Gramáticas formales

Una gramática formal es un conjunto de reglas que permiten generar cadenas válidas dentro de un lenguaje. En compiladores, las gramáticas se utilizan para describir la estructura de instrucciones, expresiones, declaraciones, ciclos, condiciones y bloques de código.

Una gramática se representa como:

G = (V, T, P, S)

V = conjunto de variables o no terminales
T = conjunto de símbolos terminales
P = conjunto de producciones
S = símbolo inicial
Elemento Función Ejemplo
No terminal Representa categorías sintácticas. E, T, F
Terminal Símbolo que aparece en la cadena final. id, +, *
Producción Regla de sustitución. E → E + T
Símbolo inicial Punto de partida de la derivación. E

5.3 Árboles de derivación

Un árbol de derivación representa gráficamente cómo una cadena se obtiene a partir del símbolo inicial de una gramática. La raíz del árbol es el símbolo inicial, los nodos internos son símbolos no terminales y las hojas corresponden a símbolos terminales.

Ejemplo:

Para la expresión id + id, el árbol muestra que la expresión se deriva desde el símbolo inicial E mediante producciones gramaticales.

5.4 Derivación izquierda y derivación derecha

En una derivación izquierda se reemplaza primero el no terminal que aparece más a la izquierda. En una derivación derecha se reemplaza primero el no terminal que aparece más a la derecha.

Tipo Descripción Ejemplo
Derivación izquierda Se expande primero el no terminal más a la izquierda. E ⇒ E + T ⇒ id + T ⇒ id + id
Derivación derecha Se expande primero el no terminal más a la derecha. E ⇒ E + T ⇒ E + id ⇒ id + id

5.5 Ambigüedad en gramáticas

Una gramática es ambigua cuando una misma cadena puede tener más de un árbol de derivación o más de una derivación válida. La ambigüedad es un problema importante en compiladores, ya que puede generar interpretaciones diferentes de una misma instrucción.

Ejemplo de ambigüedad:

La expresión id + id * id puede interpretarse de diferentes formas si la gramática no define correctamente la prioridad de operadores.

5.6 Formas Normales de Chomsky

La Forma Normal de Chomsky es una forma especial de representar gramáticas libres de contexto. En esta forma, las producciones se restringen a estructuras específicas, lo que facilita algunos algoritmos de análisis sintáctico.

A → BC
A → a

Donde A, B y C son no terminales, y a es un símbolo terminal.

5.8 Conjuntos FIRST y FOLLOW

Los conjuntos FIRST y FOLLOW son herramientas esenciales para construir analizadores sintácticos predictivos. FIRST indica con qué símbolos terminales puede comenzar una cadena derivada de un no terminal. FOLLOW indica qué símbolos pueden aparecer inmediatamente después de un no terminal.

No terminal FIRST FOLLOW
E { id } { $, ) }
T { id } { +, $, ) }
F { id, ( } { *, +, $, ) }

5.10 Caso práctico: análisis de una expresión

Consideremos la expresión:

id + id

Una gramática simple para generar esta expresión puede ser:

E → E + T
E → T
T → id

El analizador sintáctico revisa que los tokens estén colocados en un orden permitido por la gramática. Si la cadena puede derivarse desde el símbolo inicial, entonces la expresión es sintácticamente válida.

5.11 Errores sintácticos

Un error sintáctico ocurre cuando los tokens están escritos en un orden que no cumple las reglas gramaticales del lenguaje.

Error Ejemplo Explicación
Falta punto y coma int edad = 20 La instrucción no termina correctamente.
Paréntesis incompleto if (x > 5 { Falta cerrar el paréntesis.
Operador mal colocado id + * id La expresión no respeta la estructura gramatical.

Actividad 3:

Investiga qué significa que una gramática sea ambigua.

Actividad 4:

Conclusión de la unidad

El análisis sintáctico es una fase esencial del proceso de compilación, ya que permite verificar si la secuencia de tokens generada por el analizador léxico cumple con la estructura gramatical del lenguaje.

Las gramáticas, árboles de derivación, conjuntos FIRST y FOLLOW, diagramas de sintaxis y matrices predictivas permiten representar y analizar la estructura de los programas. Gracias a estos elementos, los compiladores pueden detectar errores sintácticos y organizar correctamente las instrucciones antes de pasar a fases posteriores.
