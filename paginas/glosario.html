Glosario de Conceptos

Consulta los conceptos principales de Lenguajes y Autómatas I. Este glosario funciona como apoyo rápido para comprender términos relacionados con lenguajes formales, expresiones regulares, autómatas, compiladores y máquinas de Turing.

Uso del glosario

Escribe una palabra clave en el buscador para encontrar rápidamente conceptos como token, lexema, AFD, AFND, gramática, FIRST, FOLLOW, expresión regular o Máquina de Turing.

Alfabeto

Conjunto finito y no vacío de símbolos que se utilizan para formar cadenas dentro de un lenguaje formal.

Cadena

Secuencia finita de símbolos pertenecientes a un alfabeto. También puede existir la cadena vacía, representada por ε.

Cadena vacía

Cadena que no contiene símbolos. Se representa con ε y su longitud es igual a cero.

Concatenación

Operación que une dos cadenas para formar una nueva. Por ejemplo, ab + ba = abba.

Lenguaje

Conjunto de cadenas formadas a partir de un alfabeto determinado.

Lenguaje Formal

Lenguaje definido mediante reglas matemáticas o gramaticales precisas.

Lenguaje Regular

Lenguaje que puede ser descrito mediante expresiones regulares y reconocido por autómatas finitos.

Lenguaje Libre de Contexto

Lenguaje generado por una gramática libre de contexto y reconocido por un autómata de pila.

Expresión Regular

Notación formal utilizada para representar patrones de cadenas dentro de los lenguajes regulares.

Cerradura de Kleene

Operador representado por *, que indica cero o más repeticiones de una expresión.

Operador +

Operador que indica una o más repeticiones de una expresión regular.

Operador ?

Operador que indica que un símbolo o expresión puede aparecer cero o una vez.

Autómata Finito

Modelo matemático utilizado para reconocer lenguajes regulares mediante estados y transiciones.

AFD

Autómata Finito Determinista, donde para cada estado y símbolo existe una sola transición posible.

AFND

Autómata Finito No Determinista, donde pueden existir varias transiciones para un mismo símbolo.

Estado

Situación o configuración en la que se encuentra un autómata durante el procesamiento de una cadena.

Estado inicial

Estado desde el cual comienza el funcionamiento de un autómata.

Estado final

Estado de aceptación. Si el autómata termina en él, la cadena es aceptada.

Transición

Cambio de un estado a otro dentro de un autómata al leer un símbolo de entrada.

Función de transición

Regla que indica a qué estado debe pasar un autómata según el estado actual y el símbolo leído.

Minimización

Proceso de reducir el número de estados de un autómata sin cambiar el lenguaje que reconoce.

Token

Categoría léxica generada por el analizador léxico, como identificador, número, operador o palabra reservada.

Lexema

Cadena concreta del código fuente que coincide con un patrón y pertenece a un token.

Patrón

Regla que describe la forma que debe tener un lexema para ser reconocido como token.

Analizador Léxico

Primera fase del compilador encargada de leer el código fuente y dividirlo en tokens.

Tabla de símbolos

Estructura de datos donde el compilador almacena información sobre identificadores, variables y funciones.

Error léxico

Error producido cuando aparece un carácter o secuencia que no pertenece al lenguaje definido.

Gramática

Conjunto de reglas que permiten generar cadenas válidas dentro de un lenguaje.

No terminal

Símbolo de una gramática que puede ser reemplazado por otros símbolos mediante producciones.

Terminal

Símbolo que aparece en la cadena final generada por una gramática.

Producción

Regla de una gramática que indica cómo puede reemplazarse un símbolo no terminal.

Árbol de Derivación

Representación gráfica de cómo una cadena se deriva a partir de una gramática.

Ambigüedad

Propiedad de una gramática cuando una misma cadena puede tener más de un árbol de derivación.

FIRST

Conjunto de símbolos terminales con los que puede comenzar una producción o derivación.

FOLLOW

Conjunto de símbolos que pueden aparecer después de un no terminal en una derivación.

Matriz predictiva

Tabla utilizada por analizadores sintácticos para decidir qué producción aplicar.

Análisis Sintáctico

Fase del compilador que verifica si los tokens cumplen con las reglas gramaticales del lenguaje.

Máquina de Turing

Modelo matemático de cómputo capaz de simular cualquier algoritmo mediante cinta, cabezal, estados y transiciones.

Cinta

Memoria de la Máquina de Turing, dividida en celdas donde se leen y escriben símbolos.

Cabezal

Componente de la Máquina de Turing que lee, escribe y se desplaza sobre la cinta.

Problema decidible

Problema para el cual existe un algoritmo que siempre termina y entrega una respuesta correcta.

Problema indecidible

Problema para el cual no existe un algoritmo general que lo resuelva en todos los casos.

Compilador

Programa que traduce un código fuente completo a código objeto o ejecutable.

Intérprete

Programa que ejecuta instrucciones línea por línea sin generar necesariamente un ejecutable.
